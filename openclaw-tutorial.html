🦞 OpenClaw 入门教程

自托管 AI 网关 · 多通道消息 · 你的 AI 助手

📖 什么是 OpenClaw？

OpenClaw 是一个自托管的 AI 网关，可以将你常用的聊天应用（WhatsApp、Telegram、Discord、iMessage 等）连接到 AI 助手。你只需在自己的机器（或服务器）上运行一个网关进程，它就能成为你的消息应用和 AI 助手之间的桥梁。

🌐 多通道网关

一个网关同时服务 WhatsApp、Telegram、Discord 等多个平台

🔒 自托管

运行在你的硬件上，你的数据你做主

🤖 多 Agent 路由

支持多个 AI 助手，每个会话独立隔离

📱 移动端支持

iOS 和 Android 节点配对，Canvas 支持

🚀 快速开始

1 安装 OpenClaw 
npm install -g openclaw@latest
2 初始化配置 
openclaw onboard --install-daemon

这会引导你完成配置并安装网关服务。

3 登录聊天通道 
openclaw channels login

选择你要连接的聊天平台（如 WhatsApp、Telegram 等）。

4 启动网关 
openclaw gateway --port 18789

网关启动后，你就可以通过聊天应用与 AI 助手对话了！

⚙️ 配置说明

配置文件位于 ~/.openclaw/openclaw.json。默认配置即可使用，如需自定义可参考：

{
  "channels": {
    "whatsapp": {
      "allowFrom": ["+8613800138000"],
      "groups": {
        "*": { "requireMention": true }
      }
    }
  },
  "messages": {
    "groupChat": {
      "mentionPatterns": ["@大龙虾"]
    }
  }
}
💡 提示：在群聊中，默认需要 @AI 助手名称才能触发回复，避免打扰。

🎯 核心功能

  • 多通道支持 - WhatsApp、Telegram、Discord、iMessage、企业微信等
  • 插件扩展 - 支持 Mattermost 等更多平台
  • 媒体支持 - 发送和接收图片、音频、文档
  • Web 控制台 - 浏览器仪表盘，查看会话、配置、节点
  • 会话管理 - 每个用户/通道独立会话，上下文隔离
  • 定时任务 - 支持 cron 定时提醒和任务
