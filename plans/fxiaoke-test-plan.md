# 纷享销客API测试计划

## 任务概述
测试纷享销客API连接，并尝试获取客户数据。

## 任务列表

### 任务1: 创建API测试脚本
- 创建Python脚本测试纷享销客API连接
- 实现获取access_token功能
- 实现查询客户列表功能
- 添加错误处理和日志记录

### 任务2: 执行API测试
- 运行测试脚本验证连接
- 获取实际的客户数据
- 记录测试结果和响应数据

## 依赖
- 需要用户提供纷享销客API凭证（appId, appSecret, permanentCode, userId）
- Python 3.x 环境
- requests 库

## 预期输出
- 可运行的Python测试脚本
- API连接测试结果
- 客户数据样本（如连接成功）
