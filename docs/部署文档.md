# 刀模管理系统 - 部署文档

## 1. 系统要求

### 1.1 操作系统

| 操作系统 | 版本要求 | 备注 |
|----------|----------|------|
| Windows 10 | 版本 1809 或更高 | 家庭版/专业版/企业版 |
| Windows 11 | 所有版本 | 推荐 |
| Windows Server | 2016/2019/2022 | 服务器部署 |

### 1.2 运行时环境

| 组件 | 版本要求 | 下载地址 |
|------|----------|----------|
| .NET Desktop Runtime | 10.0 或更高 | https://dotnet.microsoft.com/download/dotnet |
| Microsoft SQL Server | 2016 或更高 | https://www.microsoft.com/sql-server |

### 1.3 硬件要求

| 配置项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| CPU | 双核 1.8 GHz | 四核 2.5 GHz |
| 内存 | 4 GB | 8 GB 或更高 |
| 硬盘空间 | 2 GB 可用空间 | 10 GB 可用空间 |
| 显示器分辨率 | 1366 x 768 | 1920 x 1080 |
| 网络 | 局域网连接 | 稳定的网络连接 |

### 1.4 数据库要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| SQL Server | 2016 SP2+ / 2017 / 2019 / 2022 | 标准版/企业版/Express |
| 数据库排序规则 | Chinese_PRC_CI_AS | 中文字符支持 |

## 2. 安装步骤

### 2.1 安装 .NET 运行时

1. 访问 https://dotnet.microsoft.com/download/dotnet
2. 下载 .NET 10.0 Desktop Runtime（x64）
3. 运行安装程序，按向导完成安装
4. 验证安装：
   ```cmd
   dotnet --version
   ```

### 2.2 安装 SQL Server

#### 方案一：安装 SQL Server Express（免费版）

1. 下载 SQL Server 2019 Express：
   https://www.microsoft.com/download/details.aspx?id=101064

2. 运行安装程序，选择"基本"安装类型

3. 记录实例名称（默认为 `SQLEXPRESS`）

4. 启用 SQL Server 身份验证：
   - 打开 SQL Server Management Studio (SSMS)
   - 右键服务器 → 属性 → 安全性
   - 选择"SQL Server 和 Windows 身份验证模式"
   - 重启 SQL Server 服务

5. 创建登录账户：
   ```sql
   CREATE LOGIN sa WITH PASSWORD = 'YourStrongPassword';
   ALTER LOGIN sa ENABLE;
   ```

#### 方案二：使用现有 SQL Server

1. 确认 SQL Server 版本符合要求（2016+）
2. 获取数据库连接信息：
   - 服务器地址
   - 端口号（默认 1433）
   - 登录账户和密码

### 2.3 部署应用程序

1. **创建应用程序目录**
   ```
   C:\Program Files\DieMaking\
   ```

2. **复制程序文件**
   将以下文件复制到应用程序目录：
   ```
   DieMaking.exe
   DieMaking.dll
   DieMaking.runtimeconfig.json
   DieMaking.deps.json
   App.config
   ```

3. **创建数据目录**
   ```
   C:\DieMaking\Uploads\    # 文件上传目录
   C:\DieMaking\Backup\     # 备份目录
   C:\DieMaking\Logs\       # 日志目录
   ```

4. **配置数据库连接**
   编辑 `App.config` 文件：
   ```xml
   <?xml version="1.0" encoding="utf-8" ?>
   <configuration>
     <connectionStrings>
       <add name="DieMakingDB" 
            connectionString="server=服务器地址;user id=用户名;password=密码;database=数据库名;TrustServerCertificate=True" 
            providerName="Microsoft.Data.SqlClient" />
     </connectionStrings>
   </configuration>
   ```

5. **创建桌面快捷方式**
   - 右键 `DieMaking.exe` → 发送到 → 桌面快捷方式

## 3. 数据库配置

### 3.1 连接字符串配置

#### 本地 SQL Server Express
```xml
<add name="DieMakingDB" 
     connectionString="server=localhost\SQLEXPRESS;user id=sa;password=YourPassword;database=DieMakingDB;TrustServerCertificate=True" 
     providerName="Microsoft.Data.SqlClient" />
```

#### 远程 SQL Server
```xml
<add name="DieMakingDB" 
     connectionString="server=192.168.1.100,1433;user id=sa;password=YourPassword;database=DieMakingDB;TrustServerCertificate=True" 
     providerName="Microsoft.Data.SqlClient" />
```

#### Windows 身份验证
```xml
<add name="DieMakingDB" 
     connectionString="server=localhost;database=DieMakingDB;Integrated Security=true;TrustServerCertificate=True" 
     providerName="Microsoft.Data.SqlClient" />
```

### 3.2 数据库初始化

应用程序首次启动时会自动：
1. 检查数据库是否存在，不存在则创建
2. 检查数据表是否存在，不存在则创建
3. 初始化默认数据：
   - 管理员用户（admin/admin123）
   - 系统配置参数
   - 示例库位数据

### 3.3 手动数据库初始化

如需手动初始化数据库，执行以下 SQL：

```sql
-- 创建数据库
CREATE DATABASE [DieMakingDB]
COLLATE Chinese_PRC_CI_AS;
GO

-- 使用数据库
USE [DieMakingDB];
GO

-- 创建用户表
CREATE TABLE DM_User (
    UserID INT IDENTITY(1,1) PRIMARY KEY,
    Username NVARCHAR(50) NOT NULL UNIQUE,
    Password NVARCHAR(256) NOT NULL,
    RealName NVARCHAR(50) NOT NULL,
    Permissions NVARCHAR(500),
    Workstation NVARCHAR(50),
    IsActive BIT DEFAULT 1,
    CreateTime DATETIME2 DEFAULT GETDATE(),
    LastLoginTime DATETIME2 NULL
);

-- 创建默认管理员用户
INSERT INTO DM_User (Username, Password, RealName, Permissions, Workstation, IsActive, CreateTime)
VALUES ('admin', 'YWRtaW4xMjM=', '系统管理员', 'ALL', 'Admin', 1, GETDATE());
```

## 5. 常见问题排查

### 5.1 数据库连接问题

#### 问题：无法连接到数据库

**症状：**
- 启动程序时提示"数据库初始化失败"
- 错误信息包含"无法连接到服务器"

**排查步骤：**

1. **检查 SQL Server 服务状态**
   ```cmd
   sc query MSSQLSERVER
   ```
   或对于 Express 版：
   ```cmd
   sc query MSSQL$SQLEXPRESS
   ```

2. **检查网络连接**
   ```cmd
   telnet 服务器地址 1433
   ```

3. **检查 SQL Server 配置**
   - 打开 SQL Server Configuration Manager
   - 确保 TCP/IP 协议已启用
   - 检查端口号配置

4. **检查防火墙设置**
   - 允许 SQL Server 端口（默认 1433）
   - 或允许 sqlservr.exe 程序

**解决方案：**

```sql
-- 在 SQL Server 中启用远程连接
EXEC sp_configure 'remote access', 1;
RECONFIGURE;

-- 启用 TCP/IP
-- 通过 SQL Server Configuration Manager 操作
```

#### 问题：登录失败

**症状：**
- 错误 18456：用户登录失败

**解决方案：**

1. 确认用户名和密码正确
2. 检查 SQL Server 身份验证模式：
   ```sql
   -- 查看当前模式
   SELECT SERVERPROPERTY('IsIntegratedSecurityOnly');
   
   -- 启用混合模式（需要在 SSMS 中执行）
   -- 右键服务器 → 属性 → 安全性 → SQL Server 和 Windows 身份验证模式
   ```

3. 确认登录账户已启用：
   ```sql
   ALTER LOGIN [用户名] ENABLE;
   ```

### 5.2 应用程序启动问题

#### 问题：缺少 .NET 运行时

**症状：**
- 提示"To run this application, you must install .NET"

**解决方案：**
1. 下载并安装 .NET 10.0 Desktop Runtime
2. 重启计算机
3. 再次运行程序

#### 问题：应用程序崩溃

**症状：**
- 程序启动后立即关闭
- 出现未处理的异常对话框

**排查步骤：**

1. **查看日志文件**
   ```
   C:\DieMaking\Logs\error_YYYY-MM-DD.log
   ```

2. **检查配置文件格式**
   - 确认 App.config 格式正确
   - 确认连接字符串无特殊字符

3. **检查权限**
   - 确保应用程序目录有读写权限
   - 确保数据目录有读写权限

### 5.3 性能问题

#### 问题：查询速度慢

**排查步骤：**

1. **检查数据库索引**
   ```sql
   -- 查看表索引
   EXEC sp_helpindex 'DM_DieInfo';
   ```

2. **检查慢查询日志**
   ```sql
   -- 启用慢查询跟踪
   DBCC TRACEON(1204, -1);
   ```

3. **优化建议**
   - 确保常用查询字段已建立索引
   - 定期更新统计信息：
     ```sql
     UPDATE STATISTICS DM_DieInfo;
     ```

#### 问题：内存占用高

**解决方案：**

1. 调整连接池配置（在连接字符串中）：
   ```
   Max Pool Size=50;
   ```

2. 定期重启应用程序

3. 检查是否有内存泄漏：
   - 使用任务管理器监控内存使用
   - 使用性能监视器分析

### 5.4 数据问题

#### 问题：数据丢失

**排查步骤：**

1. 检查备份文件：
   ```
   C:\DieMaking\Backup\
   ```

2. 检查操作日志：
   ```sql
   SELECT * FROM DM_OperationLog 
   WHERE CreateTime >= DATEADD(day, -1, GETDATE())
   ORDER BY CreateTime DESC;
   ```

3. 从备份恢复数据

#### 问题：数据不一致

**解决方案：**

1. 运行数据库一致性检查：
   ```sql
   DBCC CHECKDB('DieMakingDB');
   ```

2. 修复数据：
   ```sql
   -- 更新库存状态
   UPDATE DM_DieInventory 
   SET StorageStatus = 0 
   WHERE DieID NOT IN (
       SELECT DieID FROM DM_DieBorrowRecord WHERE Status = 0
   );
   ```

### 5.5 打印问题

#### 问题：无法打印

**排查步骤：**

1. 检查打印机连接
2. 检查打印机驱动
3. 检查打印权限
4. 尝试打印到 PDF 验证

### 5.6 导入导出问题

#### 问题：Excel 导入失败

**排查步骤：**

1. 确认 Excel 格式正确（.xlsx 或 .xls）
2. 确认列名与模板一致
3. 检查数据格式（日期、数字等）
4. 确认安装了 Access Database Engine：
   https://www.microsoft.com/download/details.aspx?id=54920

## 6. 备份与恢复

### 6.1 自动备份配置

在系统设置中启用自动备份：
1. 打开"系统管理" → "系统设置"
2. 切换到"备份设置"标签
3. 勾选"启用自动备份"
4. 设置备份时间和保留天数

### 6.2 手动备份

**通过应用程序备份：**
1. 打开"系统管理" → "备份管理"
2. 点击"立即备份"按钮

**通过 SQL Server 备份：**
```sql
BACKUP DATABASE [DieMakingDB] 
TO DISK = 'C:\DieMaking\Backup\DieMakingDB_YYYYMMDD.bak'
WITH FORMAT, COMPRESSION;
```

### 6.3 数据恢复

**通过应用程序恢复：**
1. 打开"系统管理" → "备份管理"
2. 选择备份文件
3. 点击"恢复"按钮

**通过 SQL Server 恢复：**
```sql
-- 断开现有连接
ALTER DATABASE [DieMakingDB] SET SINGLE_USER WITH ROLLBACK IMMEDIATE;

-- 恢复数据库
RESTORE DATABASE [DieMakingDB] 
FROM DISK = 'C:\DieMaking\Backup\DieMakingDB_YYYYMMDD.bak'
WITH REPLACE;

-- 恢复多用户模式
ALTER DATABASE [DieMakingDB] SET MULTI_USER;
```

## 7. 升级指南

### 7.1 版本升级步骤

1. **备份数据**
   - 备份数据库
   - 备份配置文件

2. **停止应用程序**
   - 确保所有用户已退出

3. **替换程序文件**
   - 保留 App.config
   - 替换其他所有文件

4. **启动应用程序**
   - 系统将自动执行数据库迁移
   - 检查迁移结果

- 创建新表
- 添加新字段
- 更新索引

如需手动执行迁移：
```sql
-- 查看当前版本
SELECT * FROM DM_DatabaseVersion ORDER BY AppliedDate DESC;

-- 执行迁移脚本（如有）
-- 参考发布说明中的迁移脚本
```

## 8. 安全建议

### 8.1 数据库安全

1. **使用强密码**
   - 至少 8 位字符
   - 包含大小写字母、数字和特殊字符
   - 定期更换密码

2. **限制数据库访问**
   - 使用专用数据库账户
   - 限制账户权限
   - 禁用 sa 账户（生产环境）

3. **启用 SSL/TLS**
   ```xml
   <add name="DieMakingDB" 
        connectionString="server=localhost;...;Encrypt=true;TrustServerCertificate=false;" />
   ```

### 8.2 应用程序安全

1. **定期更新**
   - 及时安装 .NET 安全更新
   - 及时安装 SQL Server 补丁

2. **数据加密**
   - 敏感数据加密存储
   - 配置文件加密

3. **访问控制**
   - 启用用户权限管理
   - 定期审查用户权限
   - 禁用离职员工账户

### 8.3 网络安全

1. **防火墙配置**
   - 仅开放必要端口
   - 限制数据库端口访问

2. **VPN 访问**
   - 远程访问使用 VPN
   - 避免直接暴露数据库端口
