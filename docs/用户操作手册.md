## 1. 系统登录/退出

### 1.1 登录系统

1. 双击桌面快捷方式启动程序
2. 在登录界面输入：
   - **用户名**：admin（默认管理员）
   - **密码**：admin123（默认密码）
3. 点击【登录】按钮

![登录界面说明]
- 用户名输入框：输入您的用户名
- 密码输入框：输入您的密码（输入时显示为星号）
- 登录按钮：验证身份并进入系统
- 退出按钮：关闭程序

### 1.2 修改密码

1. 登录系统后，点击菜单【系统管理】→【个人设置】
2. 在"修改密码"区域：
   - 输入原密码
   - 输入新密码（至少6位）
   - 确认新密码
3. 点击【保存】按钮

> **提示**：首次登录后建议立即修改默认密码

### 1.3 退出登录

**方式一**：点击菜单【系统管理】→【退出登录】

**方式二**：使用快捷键 `Ctrl + Q`

**方式三**：点击主窗口右上角关闭按钮

### 1.4 主界面说明

```

├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│                                                             │
```

- **菜单栏**：访问各功能模块
- **工作区**：显示当前打开的窗体
- **状态栏**：显示当前用户、登录时间和数据库连接状态

## 2. 刀模管理

### 2.1 刀模列表

**进入方式**：点击菜单【刀模管理】→【刀模列表】

#### 功能说明

刀模列表显示所有刀模信息，支持查询、筛选、编辑等操作。

#### 界面布局

```
┌─────────────────────────────────────────────────────────────┐
│ 刀模列表                                                    │
├─────────────────────────────────────────────────────────────┤
│ 刀模编号：[________]  客户名称：[________]  [查询] [重置]    │
├─────────────────────────────────────────────────────────────┤
│ 编号    客户名称    产品名称    状态    创建时间    操作     │
│ ───────────────────────────────────────────────────────────│
│ DM001   客户A      产品A      待生产   2024-01-01  [编辑]  │
│ DM002   客户B      产品B      生产中   2024-01-02  [编辑]  │
├─────────────────────────────────────────────────────────────┤
│ 共 2 条记录  [首页] [上页] 1/1 [下页] [末页]               │
└─────────────────────────────────────────────────────────────┘
```

#### 操作说明

| 操作 | 说明 |
|------|------|
| 查询 | 输入条件后点击【查询】按钮 |
| 重置 | 清空查询条件，显示全部数据 |
| 新增 | 点击【新增】按钮添加刀模 |
| 编辑 | 点击行内【编辑】按钮修改刀模 |
| 删除 | 点击行内【删除】按钮删除刀模 |
| 审核 | 点击行内【审核】按钮审核刀模 |

#### 状态说明

| 状态 | 说明 |
|------|------|
| 待生产 | 刀模尚未开始生产 |
| 生产中 | 刀模正在生产中 |
| 已完成 | 刀模生产完成 |
| 暂不生产 | 暂时不安排生产 |
| 无需生产 | 不需要生产 |

### 2.2 添加刀模

**进入方式**：
- 点击菜单【刀模管理】→【添加刀模】
- 或在刀模列表点击【新增】按钮

#### 基本信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 刀模编号 | 是 | 唯一标识，如：DM001 |
| 客户名称 | 是 | 客户公司名称 |
| 产品名称 | 是 | 产品名称 |
| 结构类型 | 否 | 刀模结构类型 |
| 模型类型 | 否 | 模型类型 |
| 排版方式 | 否 | 排版方式 |
| 瓦楞类型 | 否 | 瓦楞类型 |
| 材料 | 否 | 使用材料 |

#### 尺寸信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 制造尺寸-长 | 否 | 制造长度（mm） |
| 制造尺寸-宽 | 否 | 制造宽度（mm） |
| 制造尺寸-高 | 否 | 制造高度（mm） |
| 下料尺寸-长 | 否 | 下料长度（mm） |
| 下料尺寸-宽 | 否 | 下料宽度（mm） |

#### 工艺信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 工艺描述 | 否 | 工艺要求描述 |
| 所需工序 | 否 | 需要的工序列表 |
| 来源工厂 | 否 | 生产来源工厂 |
| 交货日期 | 否 | 预计交货日期 |
| 备注 | 否 | 其他说明 |

#### 添加工序

1. 在工序区域点击【添加工序】按钮
2. 选择工序名称（打样、切板、弯刀、装刀、质检、入库）
3. 填写工序参数（如适用）：
   - 板长/板宽
   - 刀长/刀痕长度
   - 计算公式
4. 点击【确定】保存工序

#### 保存刀模

1. 填写完整信息后，点击【保存】按钮
2. 系统提示"保存成功"即完成添加
3. 新添加的刀模状态为"待生产"

### 2.3 编辑刀模

1. 在刀模列表中找到要编辑的刀模
2. 点击【编辑】按钮
3. 修改需要更新的信息
4. 点击【保存】按钮

> **注意**：刀模编号不可修改

### 2.4 审核刀模

1. 在刀模列表中找到待审核的刀模
2. 点击【审核】按钮
3. 在弹出的对话框中选择：
   - 【通过】：审核通过，刀模可以开始生产
   - 【驳回】：审核不通过，需要修改后重新提交
4. 填写审核意见（可选）
5. 点击【确定】完成审核

## 3. 生产管理

### 3.1 生产看板

**进入方式**：点击菜单【生产管理】→【生产看板】

#### 功能说明

生产看板以可视化方式展示所有刀模的生产状态，便于实时掌握生产进度。

#### 界面布局

```
┌─────────────────────────────────────────────────────────────┐
│ 生产看板                                                    │
├─────────────────────────────────────────────────────────────┤
│ 开始日期：[____]  结束日期：[____]  客户：[____]  [查询]    │
├─────────────────────────────────────────────────────────────┤
│ 统计：待生产 5 | 生产中 3 | 已完成 10 | 总计 18            │
├─────────────────────────────────────────────────────────────┤
│ 【待生产】        【生产中】        【已完成】              │
│ ┌──────────┐     ┌──────────┐     ┌──────────┐            │
│ │ DM001    │     │ DM006    │     │ DM010    │            │
│ │ 客户A    │     │ 客户F    │     │ 客户K    │            │
│ │ 进度:0/6 │     │ 进度:2/5 │     │ 进度:5/5 │            │
│ └──────────┘     └──────────┘     └──────────┘            │
└─────────────────────────────────────────────────────────────┘
```

#### 操作说明

- **查看详情**：双击卡片查看刀模详细信息
- **开始生产**：在"待生产"卡片上右键选择"开始生产"
- **查看工序**：点击卡片上的进度显示工序详情

### 3.2 工序报产

**进入方式**：点击菜单【生产管理】→【工序报产】

#### 功能说明

用于记录各工序的生产开始和完成，支持计算工序金额。

#### 报产流程

1. **选择刀模**
   - 在左侧列表选择要报产的刀模
   - 右侧显示该刀模的所有工序

2. **开始工序**
   - 找到状态为"待生产"的工序
   - 点击【开始】按钮
   - 输入操作员工号和姓名
   - 点击【确定】

3. **完成工序**
   - 找到状态为"生产中"的工序
   - 点击【完成】按钮
   - 输入实际金额（如适用）
   - 点击【确定】

#### 工序依赖

- 系统会自动检查前道工序是否完成
- 前道工序未完成时，当前工序无法开始
- 会弹出提示告知需要先完成的前道工序

### 3.3 完工查询

**进入方式**：点击菜单【生产管理】→【完工查询】

#### 查询条件

| 条件 | 说明 |
|------|------|
| 完工日期 | 选择完工时间范围 |
| 刀模编号 | 输入刀模编号查询 |
| 工序名称 | 选择具体工序 |

#### 查询结果

显示已完工的刀模列表，包含：
- 刀模编号、客户名称、产品名称
- 完工时间、总金额
- 操作员信息

## 4. 仓库管理

### 4.1 库位管理

**进入方式**：点击菜单【仓库管理】→【库位管理】

#### 功能说明

管理仓库的库位信息，支持库位的增删改查。

#### 库位编码规则

库位编号格式：`区域-架号-层号-位号`

示例：A-01-01-01 表示 A区1架1层1位

#### 添加库位

1. 点击【新增】按钮
2. 填写库位信息：
   | 字段 | 必填 | 说明 |
   |------|------|------|
   | 区域 | 是 | 库位所在区域，如A、B、C |
   | 架号 | 是 | 货架编号，如01、02 |
   | 层号 | 是 | 层数编号，如01、02 |
   | 位号 | 是 | 位置编号，如01、02 |
   | 描述 | 否 | 库位描述 |
3. 点击【保存】按钮

#### 库位状态

| 状态 | 说明 |
|------|------|
| 空闲 | 库位可用，无刀模存放 |
| 占用 | 库位已被占用 |
| 禁用 | 库位不可用 |

### 4.2 刀模入库

**进入方式**：点击菜单【仓库管理】→【刀模入库】

#### 入库流程

1. 选择已完工的刀模（下拉选择或扫描）
2. 选择存放库位（只能选择"空闲"状态的库位）
3. 确认入库信息
4. 点击【入库】按钮

#### 入库后状态

- 刀模库存状态变为"在库"
- 库位状态变为"占用"
- 记录入库时间

### 4.3 刀模领用

**进入方式**：点击菜单【仓库管理】→【刀模领用】

#### 领用流程

1. **选择刀模**
   - 输入刀模编号或扫描条码
   - 系统自动显示刀模信息

2. **填写领用信息**
   | 字段 | 必填 | 说明 |
   |------|------|------|
   | 领用类型 | 是 | 生产领用/外借/调拨 |
   | 领用人编号 | 是 | 领用人员工号 |
   | 领用人姓名 | 是 | 领用人员姓名 |
   | 领用部门 | 否 | 所属部门 |
   | 预计归还时间 | 否 | 预计归还日期 |
   | 用途说明 | 否 | 领用用途 |

3. 点击【确认领用】按钮

#### 领用后状态

- 刀模库存状态变为"借出"
- 库位状态变为"空闲"
- 生成借用记录
- 记录借出时间

### 4.4 刀模归还

**进入方式**：点击菜单【仓库管理】→【刀模归还】

#### 归还流程

1. **查询借用记录**
   - 输入刀模编号或领用人信息
   - 显示该刀模的借用记录

2. **选择归还记录**
   - 点击要归还的记录

3. **确认归还信息**
   - 系统自动显示借用人、借用时间等信息
   - 选择归还库位

4. 点击【确认归还】按钮

#### 归还后状态

- 刀模库存状态变为"在库"
- 库位状态变为"占用"
- 更新借用记录状态为"已归还"
- 记录归还时间

### 4.5 借用记录

**进入方式**：点击菜单【仓库管理】→【借用记录】

#### 功能说明

查询所有刀模的借用和归还记录。

#### 查询条件

- 刀模编号
- 领用人姓名
- 借用时间范围
- 状态（借用中/已归还/逾期）

#### 记录信息

| 字段 | 说明 |
|------|------|
| 刀模编号 | 刀模编号 |
| 客户名称 | 客户名称 |
| 领用类型 | 生产领用/外借/调拨 |
| 领用人 | 领用人姓名 |
| 借用时间 | 借出时间 |
| 预计归还 | 预计归还时间 |
| 实际归还 | 实际归还时间 |
| 状态 | 借用中/已归还/逾期 |

### 4.6 报废申请

**进入方式**：点击菜单【仓库管理】→【报废申请】

#### 申请流程

1. 选择要报废的刀模
2. 填写报废信息：
   | 字段 | 必填 | 说明 |
   |------|------|------|
   | 报废原因 | 是 | 报废原因说明 |
   | 报废类型 | 否 | 损坏/过期/其他 |
   | 申请人编号 | 是 | 申请人工号 |
   | 申请人姓名 | 是 | 申请人姓名 |
3. 点击【提交申请】按钮

#### 申请后流程

- 申请状态为"待审核"
- 等待管理员审核
- 审核通过后刀模状态变为"报废"

## 5. 报表查询

### 5.1 完工统计

**进入方式**：点击菜单【报表统计】→【完工统计】

#### 统计维度

- **按刀模统计**：查看每个刀模的完工情况
- **按客户统计**：按客户汇总完工数据
- **按日期统计**：按日期汇总完工数量

#### 查询条件

- 完工日期范围
- 刀模编号
- 客户名称

#### 导出数据

点击【导出Excel】按钮，将统计数据导出为Excel文件。

### 5.2 工序统计

**进入方式**：点击菜单【报表统计】→【工序统计】

#### 统计内容

| 统计项 | 说明 |
|--------|------|
| 工序名称 | 各工序的名称 |
| 总数量 | 该工序的总记录数 |
| 已完成 | 已完成数量 |
| 进行中 | 进行中数量 |
| 待生产 | 待生产数量 |
| 完成率 | 完成百分比 |
| 平均耗时 | 平均完成时间 |
| 总金额 | 工序总金额 |

### 5.3 库存统计

**进入方式**：点击菜单【报表统计】→【库存统计】

#### 统计内容

**汇总统计**
- 总库存数
- 在库数量
- 借出数量
- 报废数量
- 维修中数量

**库位分布**
- 各区域的库存分布
- 各货架的存放情况

**库存明细**
- 刀模编号、客户名称
- 存放位置
- 状态、入库时间
- 借用次数

## 6. 系统管理

### 6.1 用户管理

**进入方式**：点击菜单【系统管理】→【用户管理】

> **权限要求**：需要"用户管理"权限

#### 添加用户

1. 点击【新增】按钮
2. 填写用户信息：
   | 字段 | 必填 | 说明 |
   |------|------|------|
   | 用户名 | 是 | 登录账号，唯一 |
   | 密码 | 是 | 初始密码 |
   | 真实姓名 | 是 | 用户姓名 |
   | 权限 | 是 | 勾选分配的权限 |
   | 工位 | 否 | 工作位置 |
   | 启用状态 | 是 | 是否启用 |
3. 点击【保存】按钮

#### 权限说明

| 权限 | 说明 |
|------|------|
| 刀模管理 | 访问刀模列表和添加刀模 |
| 审核刀模 | 审核刀模信息 |
| 生产管理 | 访问生产看板和报产 |
| 仓库管理 | 访问仓库相关功能 |
| 库位管理 | 管理库位信息 |
| 报表统计 | 查看各类报表 |
| 用户管理 | 管理系统用户 |
| 系统管理员 | 所有权限 |

#### 编辑用户

1. 在用户列表中选择用户
2. 点击【编辑】按钮
3. 修改用户信息
4. 点击【保存】按钮

#### 重置密码

1. 在用户列表中选择用户
2. 点击【重置密码】按钮
3. 输入新密码
4. 点击【确定】按钮

#### 禁用用户

1. 在用户列表中选择用户
2. 取消勾选"启用"状态
3. 点击【保存】按钮

> 禁用后该用户无法登录系统

### 6.2 系统设置

**进入方式**：点击菜单【系统管理】→【系统设置】

#### 基本设置

| 设置项 | 说明 |
|--------|------|
| 系统名称 | 显示在窗口标题和登录界面 |
| 公司名称 | 报表中显示的公司名称 |
| 系统版本 | 当前系统版本号 |
| 默认分页大小 | 列表每页显示的记录数 |
| 日期格式 | 日期显示格式 |
| 文件上传路径 | 上传文件的存储位置 |

#### 安全设置

**密码策略**
- 密码最小长度
- 是否要求大写字母
- 是否要求小写字母
- 是否要求数字
- 是否要求特殊字符

**登录策略**
- 最大登录失败次数
- 账户锁定时间
- 会话超时时间

#### 日志设置

## 8. 常见问题解答

### 8.1 登录问题

**Q: 忘记密码怎么办？**

A: 请联系系统管理员重置密码。管理员在用户管理中选中您的账户，点击【重置密码】即可。

**Q: 提示"用户名或密码错误"**

A: 
1. 检查用户名是否输入正确（区分大小写）
2. 检查密码是否输入正确
3. 确认Caps Lock键是否开启
4. 如果多次失败，账户可能被锁定，请联系管理员

**Q: 提示"账户已被禁用"**

A: 您的账户已被管理员禁用，请联系管理员启用账户。

### 8.2 刀模管理问题

**Q: 无法添加刀模，提示"刀模编号已存在"**

A: 刀模编号必须唯一，请使用其他编号。

**Q: 删除刀模时提示"有关联数据，无法删除"**

A: 该刀模已有生产记录、库存记录或借用记录，需要先删除关联数据才能删除刀模。

**Q: 如何修改已审核的刀模？**

A: 已审核的刀模需要先取消审核（如果有权限），然后才能修改。

### 8.3 生产管理问题

**Q: 无法开始工序，提示"前道工序未完成"**

A: 工序有先后顺序依赖，必须先完成前道工序才能开始当前工序。

**Q: 如何查看刀模的生产进度？**

A: 进入【生产管理】→【生产看板】，可以查看所有刀模的生产状态和进度。

### 8.4 仓库管理问题

**Q: 刀模无法入库，提示"该刀模已入库"**

A: 每个刀模只能有一条库存记录，如果已入库，请先进行领用操作。

**Q: 无法领用刀模，提示"刀模不在库"**

A: 只有状态为"在库"的刀模才能领用，请确认刀模已入库。

**Q: 如何查询刀模的借用历史？**

A: 进入【仓库管理】→【借用记录】，输入刀模编号即可查询该刀模的所有借用记录。

**Q: 报废申请提交后多久能处理？**

A: 报废申请需要管理员审核，审核时间取决于管理员处理速度。您可以在报废申请列表中查看审核状态。

### 8.5 报表问题

**Q: 报表数据不准确怎么办？**

A: 
1. 确认查询条件是否正确
2. 确认数据录入是否完整
3. 尝试刷新数据（F5）
4. 如问题持续，请联系管理员检查数据

**Q: 如何导出报表？**

A: 在报表页面点击【导出Excel】按钮，选择保存位置即可。

### 8.6 系统问题

**Q: 系统运行缓慢怎么办？**

A:
1. 检查网络连接是否稳定
2. 减少查询的数据量（缩小时间范围）
3. 关闭不使用的窗口
4. 重启应用程序
5. 如问题持续，请联系技术支持

**Q: 程序崩溃或报错怎么办？**

A:
1. 记录错误信息
2. 尝试重启程序
3. 如问题持续，请联系技术支持并提供错误截图

**Q: 如何备份数据？**

A:
1. 进入【系统管理】→【备份管理】
2. 点击【立即备份】按钮
3. 或设置自动备份，系统会按设定时间自动备份

**Q: 数据丢失如何恢复？**

A: 联系系统管理员，从最近的备份文件中恢复数据。

### 8.7 打印问题

**Q: 无法打印报表**

A:
1. 检查打印机是否连接并开机
2. 检查打印机驱动是否正常
3. 尝试打印到 PDF 验证
4. 检查是否有打印权限

### 8.8 其他问题

**Q: 如何修改界面显示的语言或格式？**

A: 进入【系统管理】→【个人设置】，可以修改日期格式、分页大小等个性化设置。

**Q: 系统支持哪些浏览器/操作系统？**

A: 本系统为 Windows 桌面应用程序，支持 Windows 10/11 和 Windows Server 2016+。

**Q: 如何获取技术支持？**

A: 请联系您的系统管理员或技术支持团队，提供以下信息：
- 问题描述
- 错误截图
- 操作步骤
- 系统版本信息
