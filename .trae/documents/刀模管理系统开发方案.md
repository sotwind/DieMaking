# 刀模管理系统开发方案

## 一、项目概述

### 1.1 项目背景
基于现有未完成的刀模管理项目进行重构和完善，构建一个完整的刀模生产管理系统，实现刀模从需求接收、生产排程、工序管理到完工入库的全流程管理。

### 1.2 技术架构
- **开发环境**: Visual Studio 2026 (安装在 D:\vs2026)
- **目标框架**: .NET 10.0-windows（最新稳定版）
- **数据库**: SQL Server
- **UI框架**: Windows Forms
- **ORM**: ADO.NET (直接使用 Microsoft.Data.SqlClient)

---

## 二、三层架构必要性论证

### 2.1 三层架构定义
三层架构将应用分为：
- **表现层（UI层）**: WinForms窗体、控件、界面交互
- **业务逻辑层（BLL）**: 业务规则、流程控制、数据验证
- **数据访问层（DAL）**: 数据库操作、SQL执行

### 2.2 单人开发场景分析

#### 不建议使用三层架构的理由：
1. **开发效率降低**: 单人开发需要维护三层代码，增加不必要的跳转和文件数量
2. **代码冗余**: 简单的CRUD操作需要写三层代码，增加工作量
3. **调试复杂**: 问题定位需要在三层之间跳转

#### 建议采用的简化架构：
采用 **UI层 + Services层** 的两层架构：

```
┌─────────────────────────────────────┐
│           UI层 (WinForms)            │
│  - 窗体、控件、事件处理               │
│  - 数据绑定、界面逻辑                 │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│        Services层 (服务层)           │
│  - 业务逻辑 + 数据访问合并            │
│  - 按功能模块划分服务类               │
└─────────────────────────────────────┘
```

### 2.3 推荐架构说明
参考 `ExternalProcessing` 项目的设计：

| 层级 | 职责 | 示例文件 |
|------|------|----------|
| Forms | 窗体界面 | MainForm.cs, LoginForm.cs |
| Models | 实体类 | DieModel.cs, WorkOrder.cs |
| Services | 业务+数据 | DieService.cs, UserService.cs |
| Helpers | 工具类 | DbHelper.cs |

**优势**：
- 代码结构清晰，维护简单
- 开发效率高，适合单人快速迭代
- 业务逻辑和数据访问在同一层，减少跳转

### 5.2 核心代码示例

#### DbHelper.cs
```csharp
using System.Configuration;
using Microsoft.Data.SqlClient;

namespace DieMaking.Helpers;

public static class DbHelper
{
    private static string? _connectionString;

    public static string ConnectionString => 
        _connectionString ??= ConfigurationManager.ConnectionStrings["DieMakingDB"]?.ConnectionString
            ?? throw new InvalidOperationException("数据库连接字符串未配置");

    public static SqlConnection CreateConnection() => new(ConnectionString);

    public static object? ExecuteScalar(string sql, params SqlParameter[] parameters)
    {
        using var connection = CreateConnection();
        using var command = new SqlCommand(sql, connection);
        if (parameters.Length > 0) command.Parameters.AddRange(parameters);
        connection.Open();
        return command.ExecuteScalar();
    }

    public static int ExecuteNonQuery(string sql, params SqlParameter[] parameters)
    {
        using var connection = CreateConnection();
        using var command = new SqlCommand(sql, connection);
        if (parameters.Length > 0) command.Parameters.AddRange(parameters);
        connection.Open();
        return command.ExecuteNonQuery();
    }

    public static List<T> ExecuteQuery<T>(string sql, Func<SqlDataReader, T> mapper, params SqlParameter[] parameters)
    {
        var list = new List<T>();
        using var connection = CreateConnection();
        using var command = new SqlCommand(sql, connection);
        if (parameters.Length > 0) command.Parameters.AddRange(parameters);
        connection.Open();
        using var reader = command.ExecuteReader();
        while (reader.Read()) list.Add(mapper(reader));
        return list;
    }
}
```

### 8.1 技术选型总结
| 项目 | 选择 | 说明 |
|------|------|------|
| 开发工具 | VS 2026 | 安装在 D:\vs2026 |
| 目标框架 | .NET 10 | 最新稳定版 |
| 架构模式 | UI + Services | 适合单人开发 |
| 数据库 | SQL Server | 复用现有服务器 |
| ORM | ADO.NET | 轻量、直接 |

### 8.2 核心功能
1. **刀模全生命周期管理**: 从录入、审核、生产到完工入库
2. **工序流程管控**: 绘图→切割→弯刀→装刀→贴泡沫
3. **生产实时监控**: 看板展示、实时刷新
4. **仓库管理**: 库位管理、领用归还、报废管理
5. **数据统计分析**: 完工、工序、绩效、库存、报废统计
6. **权限控制**: 基于角色的权限管理

### 8.3 系统特点
- **类似图书馆借书模式**: 刀模像图书一样有固定存放位置，借还都有记录
- **实时库存追踪**: 清楚知道每个刀模当前在哪里（仓库/车间/已报废）
- **完整生命周期**: 从生产、入库、领用、归还到报废全程可追溯
