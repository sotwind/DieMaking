# 分页控件布局修复计划

## 问题描述

从截图中可以看到，"刀模列表"窗体中的分页控件存在问题：
- Label（显示"第1页/共1页"）的位置与"下一页"按钮重叠
- Label 的 Location 是 (980, 20)，而 btnNext 的 Location 是 (1020, 15)
- Label 的宽度是 150，所以它会覆盖到 980+150=1130 的位置
- 这导致"下一页"按钮（从1020开始）被Label遮挡

## 根本原因分析

### DieListForm.cs 中的问题布局：
```csharp
btnFirst = new Button { Text = "首页", Location = new Point(850, 15), Size = new Size(60, 28) };
btnPrev = new Button { Text = "上一页", Location = new Point(915, 15), Size = new Size(60, 28) };
lblPageInfo = new Label
{
    Text = "第 1 页 / 共 1 页 (共 0 条)",
    Location = new Point(980, 20),  // 问题：与btnNext重叠
    Size = new Size(150, 23),        // 980+150=1130，覆盖了btnNext
    ...
};
btnNext = new Button { Text = "下一页", Location = new Point(1020, 15), Size = new Size(60, 28) };  // 被遮挡
btnLast = new Button { Text = "末页", Location = new Point(1090, 15), Size = new Size(60, 28) };
```

### DieListFormOptimized.cs 中的问题布局：
```csharp
btnFirst = new Button { Text = "首页", Location = new Point(750, 15), Size = new Size(60, 28) };
btnPrev = new Button { Text = "上一页", Location = new Point(815, 15), Size = new Size(60, 28) };
lblPageInfo = new Label
{
    Text = "第 1 页 / 共 1 页 (共 0 条)",
    Location = new Point(880, 20),  // 问题：与btnNext重叠
    Size = new Size(180, 23),        // 880+180=1060，覆盖了btnNext
    ...
};
btnNext = new Button { Text = "下一页", Location = new Point(1065, 15), Size = new Size(60, 28) };  // 被遮挡
btnLast = new Button { Text = "末页", Location = new Point(1130, 15), Size = new Size(60, 28) };
```

## 修复方案

### 方案：调整控件位置，确保不重叠

正确的布局应该是：首页 -> 上一页 -> [Label] -> 下一页 -> 末页

#### DieListForm.cs 修复：
```csharp
// 分页控件 - 修复布局
btnFirst = new Button { Text = "首页", Location = new Point(700, 15), Size = new Size(60, 28) };
ApplyButtonStyle(btnFirst, ButtonStyle.Default);
btnFirst.Click += (s, e) => NavigateToPage(1);

btnPrev = new Button { Text = "上一页", Location = new Point(765, 15), Size = new Size(60, 28) };
ApplyButtonStyle(btnPrev, ButtonStyle.Default);
btnPrev.Click += (s, e) => NavigateToPage(_currentPage - 1);

lblPageInfo = new Label
{
    Text = "第 1 页 / 共 1 页 (共 0 条)",
    Location = new Point(830, 20),   // 调整位置：在btnPrev之后
    Size = new Size(180, 23),         // 适当加宽以显示完整信息
    TextAlign = ContentAlignment.MiddleCenter,
    Font = new Font(UIStyleHelper.FontName, UIStyleHelper.FontSizeNormal, FontStyle.Regular, GraphicsUnit.Point, 134)
};

btnNext = new Button { Text = "下一页", Location = new Point(1015, 15), Size = new Size(60, 28) };  // 调整位置：在Label之后
ApplyButtonStyle(btnNext, ButtonStyle.Default);
btnNext.Click += (s, e) => NavigateToPage(_currentPage + 1);

btnLast = new Button { Text = "末页", Location = new Point(1080, 15), Size = new Size(60, 28) };
ApplyButtonStyle(btnLast, ButtonStyle.Default);
btnLast.Click += (s, e) => NavigateToPage((_totalCount + _pageSize - 1) / _pageSize);
```

#### DieListFormOptimized.cs 修复：

## 实施步骤

1. **修复 DieListForm.cs**
   - 调整 btnFirst 位置从 850 到 700
   - 调整 btnPrev 位置从 915 到 765
   - 调整 lblPageInfo 位置从 980 到 830，宽度从 150 到 180
   - 调整 btnNext 位置从 1020 到 1015
   - 调整 btnLast 位置从 1090 到 1080

2. **修复 DieListFormOptimized.cs**
   - 调整 btnFirst 位置从 750 到 650
   - 调整 btnPrev 位置从 815 到 715
   - 调整 lblPageInfo 位置从 880 到 780
   - 调整 btnNext 位置从 1065 到 965
   - 调整 btnLast 位置从 1130 到 1030

3. **检查其他窗体**

   - 确保没有类似的布局问题
