# 移除查看详情按钮，双击直接进入编辑

## 任务描述
移除刀模列表窗体中的"查看详情"按钮，并将双击行操作从"查看详情"改为"进入编辑"。

## 修改计划

### 1. DieListForm.cs 修改
- [ ] 移除 `btnView` 按钮的创建和添加到控件集合
- [ ] 调整分页按钮位置（因删除按钮后左移）
- [ ] 修改 `DgvDieList_CellDoubleClick` 方法，从调用 `BtnView_Click` 改为调用 `BtnEdit_Click`
- [ ] 可选择：移除 `BtnView_Click` 方法（如不再使用）

### 2. DieListFormOptimized.cs 修改
- [ ] 移除 `btnView` 按钮的创建和添加到控件集合
- [ ] 调整分页按钮位置（因删除按钮后左移）
- [ ] 修改 `DgvDieList_CellDoubleClick` 方法，从调用 `BtnView_Click` 改为调用 `BtnEdit_Click`
- [ ] 可选择：移除 `BtnView_Click` 方法（如不再使用）

### 3. UIStyleHelper.cs 修改
- [ ] 修改 `CreateDataGridViewContextMenu` 方法，移除"查看详情"菜单项或改为"编辑"

## 详细修改内容

### DieListForm.cs

#### 修改1: 移除 btnView 按钮创建（约第149-151行）
删除以下代码：
```csharp
btnView = new Button { Text = "查看详情", Location = new Point(345, 15), Size = UIStyleHelper.SizeButton };
ApplyButtonStyle(btnView, ButtonStyle.Default);
btnView.Click += BtnView_Click;
```

#### 修改2: 从 grpButtons.Controls 移除 btnView（约第182行）
删除：
```csharp
grpButtons.Controls.Add(btnView);
```

#### 修改3: 调整分页按钮位置（约第154-177行）
将分页按钮从 Location.X = 700 调整为 565（左移一个按钮宽度+间距）

#### 修改4: 修改双击事件（约第296-300行）
```csharp
// 原代码
private void DgvDieList_CellDoubleClick(object? sender, DataGridViewCellEventArgs e)
{
    if (e.RowIndex < 0) return;
    BtnView_Click(sender, e);  // 改为 BtnEdit_Click
}
```

#### 修改5: 移除控件声明（约第210行）
删除：
```csharp
private Button btnView = null!;
```

### UIStyleHelper.cs

{
    var viewItem = new ToolStripMenuItem("查看详情", null, (s, e) => onView());
