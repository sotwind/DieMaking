# 添加刀模入库菜单及库存查询功能计划

## 问题分析

### 当前问题
1. **刀模入库菜单缺失**：主菜单中没有"刀模入库"菜单项，导致用户无法进行入库操作
2. **刀模领用无数据**：刀模领用窗体的下拉框数据来源是 `DM_DieInventory` 表中状态为"在库"的记录，但没有入库功能就无法产生这些数据
3. **缺少库存查询窗体**：用户无法查看当前库存情况

### 数据流向
```
刀模生产完成 → 刀模入库 → DM_DieInventory(在库状态) → 刀模领用
```

## 业务流程说明

### 完整业务流程
1. **刀模生产** → 在"刀模管理"中创建刀模信息，完成生产工序
2. **刀模入库** → 通过"刀模入库"功能将完工刀模入库到指定库位
3. **刀模领用** → 通过"刀模领用"功能从库存中领用已入库的刀模
4. **刀模归还** → 使用完毕后通过"刀模归还"功能归还刀模

### 数据状态流转
```
生产完成 → 入库 → 在库状态 → 领用 → 借出状态 → 归还 → 在库状态
```
